# DevOpsHub

Production-style DevOps practice project.

## Technology Stack

- AWS
- Linux / Ubuntu
- Git / GitHub
- Node.js
- React
- PostgreSQL
- Redis
- Nginx
- PM2
- Docker
- Jenkins
- Terraform
- Prometheus
- Grafana

## Project Architecture

This project will be developed as a three-tier application:

Frontend → Backend API → Database

The infrastructure and deployment will gradually be automated using
Docker, Jenkins, Terraform, and AWS services.
